# Directory listing images

Images for the listing of Better Cooking in the Obsidian community directory. All images show the browser preview (`pnpm preview`) with the self-written example recipes of `tests/fixtures/`, English interface (`lang=en`). Nothing in them is private data. The food photos on the recipe cards and pages were added only while taking the screenshots; they are not part of this repository.

Order for the listing (desktop and phone are meant to be shown as two groups):

| #   | Desktop, 1200 x 800 px         | Shows                                                  | Theme |
| --- | ------------------------------ | ------------------------------------------------------ | ----- |
| 1   | `desktop-1-overview.png`       | Overview with recipe cards, lists and categories       | light |
| 2   | `desktop-2-recipe-dark.png`    | Recipe page with servings calculator and timer buttons | dark  |
| 3   | `desktop-3-shopping-list.png`  | Shopping list with sections per store                  | light |
| 4   | `desktop-4-meal-plan-dark.png` | Meal plan with the days of the week                    | dark  |
| 5   | `desktop-5-editor.png`         | Recipe editor (new in 0.9)                             | light |

| #   | Phone, 900 x 1600 px            | Shows                                                       | Theme |
| --- | ------------------------------- | ----------------------------------------------------------- | ----- |
| 1   | `phone-1-overview.png`          | Overview                                                    | light |
| 2   | `phone-2-recipe-dark.png`       | Recipe page                                                 | dark  |
| 3   | `phone-3-cooking-mode-dark.png` | Cooking mode with a running timer                           | dark  |
| 4   | `phone-4-shopping-list.png`     | Shopping list with the amounts per recipe of an opened line | light |
| 5   | `phone-5-meal-plan-dark.png`    | Meal plan                                                   | dark  |

Phone images are taken at a viewport of 450 x 800 px with device scale factor 2 and touch emulation; desktop images at 1200 x 800 px, factor 1.

## Suggested short description (about 250 characters)

> Browse, search and cook your recipe notes: card overview, instant offline search, servings calculator, step-by-step cooking mode with timers, shopping list, meal plan, and import from a link or your own AI.

## Suggested keywords

The directory has no fixed category list; the manifest `description` and the README are what it shows and searches. Keywords that fit: recipes, cooking, cookbook, meal plan, shopping list, timer, schema.org.
